# 와방 · 매물 사이트 + 매물 접수 챗봇

| 화면 | 주소 | 누가 |
|---|---|---|
| 매물 사이트 | https://bu-room.github.io/siteandchat/ | 손님 |
| 챗봇 | https://bu-room.github.io/siteandchat/chat/ | 손님 |
| 문의 상세 | https://bu-room.github.io/siteandchat/admin/?id=…&k=… | 중개사 (카톡 알림/시트 링크로만 열림) |

## 흐름
1. 챗봇에서 조건 접수 → `?chat=` 으로 매물 사이트에 조건 자동 적용
2. 손님이 ♡ 담기 → 중개사에게 보내기 (바로 전송 / 카톡·문자·인스타 복사)
3. 바로 전송 시: Apps Script가 문의번호 부여 → 시트 '문의접수' 기록 → 중개사 카톡 요약 알림
4. 중개사는 [문의 전체 보기]로 매물 사진·조건 비교·비공개 정보(관리용 탭)·전화/문자 답장·상태/메모 관리

## 설정
- 서버: `apps-script/문의접수.gs` 맨 위 설치 순서대로 배포 → 웹앱 주소를 `index.html` 의 `CONFIG.INQUIRY_URL` 에 입력
- 비공개 정보: 구글 시트에 **'관리용'** 탭을 만들고 `매물번호 | 상세주소 | 임대인 연락처 | …` 형식으로 입력 (공개 매물 탭에는 적지 말 것)
- 카카오톡 알림: 마지막 단계 (스크립트 [5]번)
